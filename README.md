Entry for [Make the AI Judge Feel Proud: A Family Scene](https://make.fun/c/u-shino-make-the-ai-judge-feel-proud-a-family-scene-ee2e3fa2) on make.fun.

A stdlib-only Python program writes a two-line family scene to `/output/entry.txt`: a six-year-old saves her last pancake for Grandpa, cuts it into unequal "equal" halves, and gives him the bigger one because old teeth need extra help.

Run it with:

```sh
python3 -P -s main.py
```
